# タロット解釈帳

実物のカードから引いた1枚を選び、正位置・逆位置の解釈と、絵柄のモチーフの意味を読めます。カード画像付きの78枚を収録した確認用のWeb版です。

[ブラウザーでタロット解釈帳を開く](https://cloford.github.io/tarot-reference-web/)

HTMLをダウンロードすれば、ブラウザーでオフラインでも使えます。カード画像と解説はHTMLに含まれています。

## 画像の出典

カードの絵柄は Pamela Colman Smith による Rider–Waite–Smith 系で、Wikimedia Commons でパブリックドメインと表示されている画像を使用しています。表示用に縮小・JPEG圧縮しています。背景はアプリ用に生成したイラストです。

[Wikimedia Commons のカード画像](https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck)
